# Reading notes

One file per school per year: `notes/<year>/<SCHOOL>.md`. Written while reading every source file, so the consolidation can be built from notes without re-reading ~750k words.

Each file records, per paper (H1 P1 8834/01; H2 P1 9173/01; H2 P2 9173/02):
- Full question wording + marks, section/cluster, short topic tag(s)
- Resources in the Insert (what they show; place/case study)
- Answer scheme: available or not; key points / approaches / examples worth keeping
- Files read and any issues (duplicates skipped, unreadable files, image-only content)

Topic tags (shorthand used in the 2024 grids): CC = climate change, SUD = sustainable urban development, SD = sustainable development, EI = environmental issues, GPN = global production networks, MI = multilateral institutions, RE = renewable energy, MM = mass movement, GI = geographical investigation (fieldwork), EF = ecological footprint.
